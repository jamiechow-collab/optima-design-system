<Title>Alert banner</Title>
<Subtitle>
  Alert banner is a powerful communication tool used to display important messages prominently
  across the user interface. These messages can range from critical system-wide issues, such as
  errors or warnings, to informational or success messages.
</Subtitle>

Alert banners are usually placed at the top of a page and include a clear message and, if
necessary, an action for the user to take. If the notification is temporary, use Toast
notification instead for notification that triggered by specific micro-actions.

## Anatomy

<Unstyled>
  <AnatomyExample />
</Unstyled>

An alert banner is composed of a **Container**, an **Icon with background** (optional), a
**Title**, a **Body** (optional), a **Primary Button** (optional), a **Secondary Button**
(optional), and a **Close Icon Button**.

## Types

There are five types of alert: Default, Message, Positive, Negative, Warning.
