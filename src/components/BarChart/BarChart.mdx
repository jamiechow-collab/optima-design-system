## Overview

The bar chart renders a series of vertical bars of varying height above a baseline axis. Pass a
custom `data` array of bar heights (in px) to represent a different dataset — it defaults to the
reference dataset shown above.

```tsx
<BarChart data={[20, 9, 25, 33, 8, 10, 26]} />
```
