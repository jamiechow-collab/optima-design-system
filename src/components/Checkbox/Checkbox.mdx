## Overview

Checkboxes are used for multiple choices, not for mutually exclusive choices. Each checkbox works
independently from other checkboxes in the list, therefore checking an additional box does not
affect any other selections.

Examples of usage includes forms, filtering, terms & conditions.

## Interactions

**Mouse**

Users can trigger an item by clicking the checkbox input directly or by clicking the checkbox
label. Having both regions interactive creates a more accessible click target. The only hover
effect when the mouse is placed over the target is a pointer shape change.

**Keyboard**

Users can navigate to and between checkbox inputs by pressing **Tab** or **Shift-Tab**. Users can
trigger a state change by pressing **Space** while the checkbox input has focus.
