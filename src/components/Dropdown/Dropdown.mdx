## Overview

`Dropdown` (Basic), `ComboBox`, and `ComboBoxMultiSelect` share the same field-and-popover
anatomy — a field the user clicks (or types into), and a menu of options that opens beneath it.

```tsx
<Dropdown
  options={[{ value: 'a', label: 'Item A' }, { value: 'b', label: 'Item B' }]}
  value={value}
  onChange={setValue}
/>
```

## Anatomy

<Unstyled>
  <AnatomyExample />
</Unstyled>

A dropdown is made up of an optional field title, a field container (showing a placeholder or the
current selection, plus a chevron that flips between down/up as the menu opens and closes), and
the menu popover itself — a list of selectable options, reusing [Menu](?path=/docs/components-menu--docs).

## Types

There are three types of dropdown.

<Unstyled>
  <TypesExample />
</Unstyled>

**Basic** — a single-selection field the user clicks to choose from a fixed list. Not typeable.

**Combo Box (single select)** — a typeable field that filters the option list as the user types.
Once a selection is made, a dismiss ("x") icon appears to clear it back to empty.

**Combo Box (multi-select)** — like the single-select Combo Box, but each selection appears as a
tag inside the field, and multiple options can be selected at once. A dismiss icon clears every
selection; each tag also has its own remove icon.

## Interactions

**Mouse** — Clicking the field (or its chevron) opens the menu; clicking an option selects it and
closes the menu. Clicking outside the field or menu closes it without changing the selection.

**Keyboard** — **Tab** brings focus to the field. **Enter**, **Space**, or **Arrow Down** opens the
menu. Once open, **Arrow Up**/**Arrow Down** move between options and **Enter** selects the
focused one. **Esc** closes the menu and returns focus to the field.

**Typing** (Combo Box only) — typing in the field opens the menu and filters options to those
matching the entered text. Clearing the field (or pressing the dismiss icon) removes the current
selection.
