## When to use

A user's understanding of an icon is based on previous experience. Due to the absence of a
standard usage for most icons, text labels are necessary to communicate the meaning and reduce
ambiguity.

Rules of testing an icon:

1. **Keep the design simple and schematic.** Reduce the amount of graphic details by focusing on
   the basic characteristics of the object rather than creating a highly realistic image in order
   to speed up recognition. (Intricate details are difficult to distinguish at smaller sizes.)
2. **Use the 5-second rule.** If it takes you more than 5 seconds to think of an appropriate icon
   for something, it is unlikely that an icon can effectively communicate that meaning.
3. **Test the icons for recognisability:** Ask people what they expect the icons to stand for.
4. **Test the icons for memorability:** Ask a repeat set of users if they can remember the icon's
   meaning after being told what it represented a couple weeks earlier.

## Variant

### Size

There are four sizes: Extra Small, Small, Medium, Large (xs, sm, md, lg). Default size is Small.
Limit the use of Extra Small size, only use it when space is limited (e.g. on small badges).

### Basic icons

The core UI icon set — navigation, actions, alerts, charts, and editorial glyphs. Every icon
renders with `currentColor`, so it inherits text colour from its container. Open the **Basic
Icons** page in the sidebar and use the `size` control to switch between xs/sm/md/lg.

<Canvas of={IconStories.BasicIcons} />

### Channel icons

Brand marks for the social platforms, browsers, and messaging channels users connect through. Like
basic icons, these render with `currentColor`. See the **Channel Icons** page in the sidebar to
play with sizes.

<Canvas of={IconStories.ChannelIcons} />

### Country icons

Circular country flags for locale and region pickers. Unlike basic and channel icons, these keep
their own flag colours rather than inheriting `currentColor`. See the **Country Icons** page in
the sidebar to play with sizes.
