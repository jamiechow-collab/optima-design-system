## Overview

The line chart renders a small trend sparkline alongside a label. Use the default (positive,
green) variant for an upward trend, or the negative (red) variant for a downward trend — both the
sparkline and label share the same colour.

```tsx
<LineChart label="Revenue" negative={false} />
```
