## Overview

`NavTabList` renders a group of `NavTab`s and owns none of the selection state — pass `active` to each
`NavTab` and handle its `onClick` yourself. Pair with `NavTabPanel` (or your own conditional rendering)
to show the selected tab's content.

```tsx
const [active, setActive] = useState('overview');

<NavTabList variant="pill" aria-label="Account sections">
  <NavTab active={active === 'overview'} onClick={() => setActive('overview')}>
    Overview
  </NavTab>
  <NavTab active={active === 'notification'} onClick={() => setActive('notification')}>
    Notification
  </NavTab>
</NavTabList>;
```

A tab list is made up of one or more tabs, each an optional icon, a label, and an optional badge
(e.g. an unread count). Exactly one tab is active at a time.

## Horizontal tabs

Two styles: **Pill** — a bordered box of boxed tabs, best for switching between a small, equally
weighted set of views. **Underline** — a bottom-border style that reads lighter, better suited to
sitting directly above the content it controls.

## Vertical tabs

Stacks tabs in a column — each tab is full width, and the active one gets its own bordered box.
Best for a sidebar-style section switcher.

## Interactions

**Mouse** — Clicking a tab makes it active and shows its panel.

**Keyboard** — Users can press **NavTab** to move focus into the tab list (landing on the active
tab), then use the **Arrow keys** (Left/Right for horizontal, Up/Down for vertical) or **Home**/
**End** to move between tabs — moving focus also activates the tab, following the standard tabs
keyboard pattern. Pressing **NavTab** again moves focus out to the active panel's content.
