## Overview

Radio buttons are used for mutually exclusive choices, not multiple selections — unlike a
checkbox, selecting one radio button in a group automatically deselects any other option in that
same group. Give every radio button in a group the same `name` so the browser enforces this.

Examples of usage include forms, settings, and single-choice questions.

## Interactions

**Mouse**

Users can select an option by clicking the radio input directly or by clicking its label. Having
both regions interactive creates a more accessible click target. Clicking an already-selected
option deselects it, unlike a native radio button — clearing the answer is always possible.

**Keyboard**

Users can navigate to a radio group by pressing **Tab**, then move focus between options within
the group with the **Arrow keys**. Moving focus never selects an option by itself — only
**Space** or **Enter** selects (or deselects, if already selected) the currently focused option.
