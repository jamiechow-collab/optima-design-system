## Overview

Search behaves like a text input, with a leading search icon and a clear button at the end of the
field. The clear button only appears once the user has entered something, and empties the field
in one press.

  <OverviewExample />
</Unstyled>

### When to use

- To help users find data more efficiently within a complex or large data set.
- Use at a global level when searching an entire site.
- Use at a page level when searching through content on one page specifically.
- Use at a component level when searching data in a component, like a data table.

### When not to use

- Do not use when there is small or limited amounts of data.
- Do not use when the information is simple and can be found easily within one view.

## States

All types of search have an Empty and a Filled state. Empty is when there is no entry, Filled is
when an entry has been submitted. Within each, the field can be Default, Hover, Active, Focused,
Disabled, or (once filled) Read only.

## Interactions

**Mouse** — Users press the field container to start typing. When they click elsewhere on the
interface, the field goes back to its default state. Pressing the clear button empties the field
and returns focus to it.

**Keyboard** — Users can press **Tab** to bring focus to the search field, and **Tab** again to
reach the clear button. **Enter** or **Space** on the clear button empties the field.

**Esc** clears the field while it has an entry.

**Opt + up/down arrows** relocates the caret to the start or end of the input content.
