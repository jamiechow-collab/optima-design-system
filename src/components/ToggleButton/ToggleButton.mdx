## Overview

Toggle button follows the same behaviour as Button as the base. Except, it has a state to show if
the filter is on or active.

</Unstyled>

## Variants

There are two variants for Toggle Button, which show if the state is inactive, or when a user has
pressed on the toggle button and it is now active.

## Types

There are three types of Toggle Button. With label only is the default one, use a leading icon if
it helps users by providing more context.

The one with a badge could show how many filter items are being applied, but its use case is
still TBD.

## Interactions

**Mouse**

Users can toggle the Toggle Button on and off by clicking within the container.

**Keyboard**

Users can toggle a Toggle Button on by pressing **Enter** or **Space** while the Toggle Button has
focus, and pressing **Enter** or **Space** again to toggle it off.
